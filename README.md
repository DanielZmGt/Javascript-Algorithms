# 🎖️ [Daniel Zamudio] Javascript Algorithms Portfolio

> **Status:** Operational & Deployed
> **Interface:** TF HUD

## 📡 SYSTEM OVERVIEW

This repository houses a collection of JavaScript algorithms integrated into an interactive, high-fidelity web interface. Instead of static code snippets, this portfolio uses a **Dynamic Injection Engine** to execute logic from my practice and certification projects directly in the browser.

Thanks for visiting!

## 🛠️ STACK

* **Logic Engine:** Pure JavaScript (ES Modules).
* **Automation:** A custom Node.js refactor pipeline using **Esprima** for AST (Abstract Syntax Tree) analysis.
* **Manifest System:** Generates `algorithms-manifest.json` to map function exports, parameters, and complexity telemetry automatically.

## 📂 DIRECTORY STRUCTURE

* `/basic-logic/web-apps`: The web-apps
* `/basic-logic/algorithms`: The core logic modules.
